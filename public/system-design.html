System Architecture Design

End-to-end cloud architecture decoupling the Data Plane, Control Plane, and Zero-Trust Persistence.

1 · HTTPS

HTTPS: Reader requests technical articles over secure HTTPS

2 · EDGE SSR

EDGE SSR: Vercel Edge serves cached static HTML or proxies dynamic SSR requests

3 · SQL POOL

SQL POOL: Astro serverless API increments views & reactions via Prisma connection pool

4 · NOTION

NOTION: Author creates and edits technical articles within Notion CMS workspace

5 · CRON

CRON: GitHub Actions daily cron (00:00 UTC+7) fetches updated MDX from Notion

6 · DEPLOY

DEPLOY: Automated workflow validates MDX, builds static bundle, and triggers edge deployment

7 · VAULT

VAULT: Secure environment vault injects encrypted runtime secrets & DATABASE_URL into Astro

8 · AI TOKEN

AI TOKEN: Astro queries private telemetry store for LLM token usage and spend tracking
